# Put the Behance images here

- Drop the portfolio images into this folder, **named in display order**:
  `01.jpg`, `02.jpg`, `03.jpg` … (any size; jpg, png, webp, gif, avif or svg).
- That is it. They appear on the site automatically, top to bottom, in filename
  order. There is no list to edit.
- To reorder: rename. To remove: delete the file.
- The dev server reloads itself when you add or remove images here.
